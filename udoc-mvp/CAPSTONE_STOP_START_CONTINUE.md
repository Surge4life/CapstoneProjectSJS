# Capstone · Stop / Start / Continue

**Updated:** 2026-07-31  
**Source alignment:** Final external CTO assessment (Volume 4 Part 8) + project constraints + EDR-001 / EDR-002  
**Purpose:** Discipline list so the finish line does not move every month.

---

## STOP

| Stop | Why |
|------|-----|
| Rebuilding authentication for aesthetics | Working path exists; hours belong to smoke + substrate |
| Redesigning folder trees every month | Organisation > novelty |
| Inventing new named layers without an EDR | Scope expansion is the largest risk |
| Continuous terminology churn | Assessors need stable words |
| Adding diagrams/philosophy without shipping a verified loop | Docs that never feed a demo become drag |
| New Render services for features that fit existing hosts | Quota + Neon limits |
| Claiming commercial / Enterprise / sovereign readiness | Not Capstone success criteria |
| Expanding GIS/GBS product before live UDOC smoke green | EDR-001 order |

---

## START (or keep finishing)

| Start | Done when |
|-------|-----------|
| **Live smoke honesty** | Operator records biased = BLOCK on Client + Sentinel (M7) |
| **One complete governance journey** | Policy → rules → decision → audit (already largely live; prove it) |
| **Intent artefacts current** | Roadmap + EDRs updated when direction changes |
| **Knowledge Substrate naming** | Corpus/policy/Canon described as substrate (EDR-002), not “extra docs” |
| **Freeze working modules** | Only bug/smoke fixes on freeze list |
| **Capstone evidence pack** | Smoke notes, links, package story for assessors |

Finish the **smallest complete UDOC** that shows deterministic governance, human oversight, and end-to-end workflow. New ideas earn a place only if they strengthen that demonstration.

## Six-month / one-year framing (not commitments)

| Horizon | Intent |
|---------|--------|
| Capstone (March 2027) | One excellent working UDOC MVP + written intent + live smoke |
| After Capstone | Community packaging story (run, limits, honesty) if useful |
| Later | Professional / Enterprise / institutional only if isolation, ops, and users justify — not from architecture slides alone |

Enterprise roadmap items (SSO, connectors, national sovereign deploy, multi-level org hierarchy) are **valid future packaging**. They are **out of Capstone scope** unless they fix a live smoke or honesty failure.

---

## One sentence

**Freeze the foundation. Build upward. Demonstrate one complete governance workflow. Then release — and keep the Knowledge Substrate intentional, not accidental.**
