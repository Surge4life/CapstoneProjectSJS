# UDOC Capstone · Glossary

**Purpose:** Shared meanings so assessors and collaborators read the same intent.  
**Date:** 2026-07-31  
**Scope:** Terms as used in this repository under free-tier Capstone constraints.

---

| Term | Meaning in this project |
|------|-------------------------|
| **UDOC** | Unified Digital Oversight & Coordination — the **operational product** layer users open (Client, Internal, Citizen, Gateway). |
| **G.O.D.S** | Constitutional / holdings authority and ecosystem name. Not a separate free-tier customer app in this Capstone. |
| **GBS** | Constitutional governance framework (franchise / division structure). Documented; full runtime deferred. |
| **GIS** | Deterministic governance intelligence (corpus → rules → evaluation). Engines may exist under Core; product depth controlled by UDOC and deferred until smoke honesty. |
| **EVA** | Evaluation path (6-dimensional scoring, fail-closed, certificates). Runs inside UDOC runtime (e.g. Sentinel, Govern). |
| **Internal package** | Staff-facing UDOC: Admin, Operator, Sentinel, Core `/portals`, Core `/admin`. May include kill-switch / jobs. |
| **Client package** | Tenant-facing UDOC: Client Web/Desktop, App/Mobile, SaaS Portals. No staff hardware plane as product. |
| **Citizen** | Public AI-rights surface; no login required for core challenge/status/rights UX. |
| **Gateway** | Sign-on router that sends roles to the correct package host. |
| **Core** | `gods-platform-core` — single API process + Neon state. |
| **Demo seed** | Fixed model + ACTIVE policy pack used for repeatable smoke (`/udoc/demo/ready`). |
| **Task 2** | Live demo-parity / density work; closes when operator verifies biased = **BLOCK** on live Client + Sentinel. |
| **Task 1** | Broader Canon / infrastructure documentation track; sequenced after Task 2 honesty in this programme. |
| **Fail-closed** | Prefer BLOCK / deny when evidence, policy, or seed is insufficient — not silent allow. |
| **Policy-to-code** | Upload/compile/activate policy packs so rules enforce inside the EVA decision path. |
| **OversightCase** | Neon-backed case record used by citizen challenge and portal dual-path controls. |
| **Dual-path portals** | Core `/portals` controls that open or resolve OversightCase (or audit) live — not headings-only. |
| **EDR** | Engineering Decision Record — durable “why we chose X” note. |
| **Capstone bar** | Internal path · Client path · Citizen · Gateway · live biased = BLOCK — with intent documented. |
| **Commercial SaaS** | Paid multi-tenant operations readiness. **Not** claimed; see gap doc. |
| **Pre-registration** | Honesty posture: legal entities/trademarks may be forecast, not asserted as registered fact. |
