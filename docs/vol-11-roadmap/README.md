## The Trajectory

```
Current Repository (built, tested, deployed to Render)
  ↓
Production (CIPC registration, entity formalisation, first client)
  ↓
Pilot (1–3 clients, real governance data, hardware node v1)
  ↓
Regional (South African province, sector-specific deployment)
  ↓
National (National government or large institution, UDOC nodes live)
  ↓
International (Africa-first, then Commonwealth)
  ↓
250-Year Governance Infrastructure
```

---

## Governing Principle of the Roadmap

Every milestone is a governance milestone first, a technology milestone second.

The question at every stage is not "what can we build?" but "what governance guarantees can we provide, to whom, with what level of accountability?"

Technology that cannot answer that question does not advance the roadmap.
