# G.O.D.S Intellectual Property Repository
Structured store for patent lifecycle artifacts (per external assessment gap #9).
- prior-art/ — search results, references, FTO inputs (completed by patent attorney)
- claims/ — claim sets and dependency maps
- diagrams/ — figures (the GODS/UDOC architecture + invention figures)
- evidence/ — engineering evidence backing claims (code, test results, this ecosystem)
- filings/ — provisional/complete/PCT filing copies
- examiner-responses/ — office actions and responses
NOTE: organisation only. Patentability/FTO opinions require a registered patent attorney.
